Fulfillment workflow

Designed around exception-driven work
1. Order received → processing
Office reviews order, validates SKU/variant, and selects courier based on cutoff, service level and cost.
2. Picking
Picker sees exact SKU, variant and source location. If main stock is insufficient, a transfer task is created instead of silently failing.
3. Packing → staging
Packing confirms quantity and order ID before label attachment. Staged boxes are assigned a visible pickup status.
4. Shipping
Courier pickup is tracked against the expected pickup window. Missed pickup becomes an exception.
5. Exception loop
Every blocker has an owner, severity and next action so unresolved problems remain visible.
